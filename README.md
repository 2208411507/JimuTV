# 极幕桌面

**给电视准备的清爽大屏桌面。** 用遥控器轻松切换常用应用，也可以换上自己喜欢的图片或视频壁纸。

> 极幕桌面是一款面向 Android TV 和电视盒子的第三方桌面应用，采用多种风格的大屏布局。

## 下载

**当前版本：2.0.0** · Android 6.0 及以上

## 主要功能

- **电视大屏布局**：Apple TV 风格的应用栏、清晰焦点和遥控器导航。
- **常用应用置顶**：首页最多放置六个常用应用；向下展开可浏览已安装的应用。应用需要先安装在电视上，桌面不会代替视频平台客户端。
- **电视应用图标适配**：内置常见电视应用的横向图标适配；应用自带的电视横幅或横向图标会优先使用。
- **图片和视频壁纸**：提供内置静态壁纸与轻动态壁纸，也可导入本地图片或视频作为壁纸。视频静音循环播放，格式和实际播放效果取决于电视的解码能力。
- **应用开关动画**：应用启动和返回时提供桌面过渡动画；可在桌面设置中关闭。
- **桌面外观设置**：可调整首页布局、主题、桌面名称和动画偏好。

## 安装

1. 在 Releases 下载最新的 `JimuTV-2.0.0.apk`。
2. 将 APK 复制到电视，使用电视文件管理器打开；按系统提示允许该文件管理器安装应用。
3. 打开“极幕桌面”。如需设为默认桌面，进入右上角 **… → 运行与内存 → 设置为默认桌面**，然后在系统提示中选择极幕桌面。

也可以通过 ADB 安装：

```bash
adb install -r JimuTV-2.0.0.apk
```

从较早版本升级时，可直接覆盖安装并保留现有设置、应用顺序和自定义壁纸。是否能设为默认桌面、以及具体菜单名称，可能因电视厂商系统而异。

## 自定义壁纸

在桌面右上角打开 **… → 壁纸**，选择本地图片或视频。导入后文件保存在应用私有目录，不需要一直连接 U 盘。视频文件最大 256 MiB；分辨率、帧率和编码能否流畅播放取决于电视硬件和系统解码器。

## 隐私与权限

当前版本不申请联网或全盘存储权限，也不包含网络下载或统计 SDK。壁纸与桌面设置保存在本机应用私有目录。启用“启动动画保护”等可选功能时，系统可能会提示授予“显示在其他应用上层”权限；不启用该功能也可以正常使用桌面。
